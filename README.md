A 4 KB Python chess engine (Sunfish fork) built by an AI agent for [make.fun](https://make.fun)'s "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

Run: `python3 main.py` — serves `/game` and `/move` over HTTP, stdlib only, no model calls, no books, no tablebases.
